**GSAP** (GreenSock Animation Platform) is a JavaScript library for web animation. It's the reference standard for sites with polished motion: agencies, brands and award-winning design sites rely on it. Since 2024 it has been part of **Webflow** and, since then, it's free for everyone, including the plugins that used to be paid.[^gsapfree]

This site uses it too: the horizontally scrolling sections, the parallax and the headlines that slide into view are animated with GSAP.

### How it works

- **Animates anything**: text, images, SVG shapes, 3D elements, colours, numbers. If a browser can display it, GSAP can animate it.
- **Timelines**: animations are sequenced like on a video timeline, with precise timing and overlaps. They can be paused, reversed or sped up.
- **ScrollTrigger**: ties animations to scrolling. A section "pins" while content moves sideways, a product assembles itself as the user scrolls, a number counts up when it comes into view. It's the plugin that makes *scroll storytelling* possible.
- **Plugins for specific effects**: text split into letters and words (SplitText), shapes that morph into one another (MorphSVG), draggable elements (Draggable), smooth transitions between layouts (Flip).
- **Works everywhere**: on any site (Shopify, WordPress, Next.js, Astro, static sites) and on all modern browsers, smoothing over their differences.

### Typical use cases

- **Landing pages and product launches**: the product is revealed through an animated sequence as the user scrolls, like on the pages of big tech brands.
- **Scroll storytelling**: telling a process, the brand story or a product's journey section by section.
- **Brand sites and portfolios** where the visual experience is part of the message.
- **Micro-interactions**: buttons, menus, add-to-cart, notifications that respond smoothly and clearly.
- **Premium Shopify themes**: entrance animations, galleries and more engaging product pages, without slowing the store down.
- **Infographics and animated numbers**, to make data and results easier to read.
- **Alongside WebGL and 3D**: coordinating three.js scenes with scrolling and the rest of the page.

### Advantages

- **Performance**: optimised for smooth animation even on low-powered devices.
- **Full control**: timing, sequencing and scroll sync are precise, which is hard to achieve with CSS animations alone.
- **Reliability**: more than 15 years of development, consistent behaviour across browsers.
- **Free**, including every plugin.
- **Independent of the site's technology**: it fits any platform or framework.
- **Excellent documentation and community**, with a very active forum.

### Disadvantages

- **Extra weight**: it's additional JavaScript to download. Load it only on the pages that need it.
- **The risk is overdoing it**: too much animation distracts, slows reading and can hurt perceived performance. An animation should guide attention, not steal it.
- **Accessibility needs care**: people with vestibular disorders can be bothered by motion. The operating system's "reduce motion" setting must be respected (this site does: with the setting on, animations are disabled).
- **Mobile**: scroll-driven effects must be designed and tested on smartphones too, where scrolling behaves differently.
- **Licence**: it's free but not open source in the strict sense. It can't be used to build tools that compete with Webflow (which doesn't affect a normal website).[^gsaplic]

### Comparison with alternatives

| | GSAP | CSS animations | Motion (formerly Framer Motion) | Anime.js | Lottie |
| --- | --- | --- | --- | --- | --- |
| Type | JavaScript library | Native to the browser | Library for React (and JS) | JavaScript library | Animations exported from After Effects |
| Weight | Medium | None | Medium | Low | Medium (plus the animation file) |
| Scroll-driven animation | Excellent (ScrollTrigger) | Possible, support growing | Good | Basic | Must be wired up |
| Complex sequences | Excellent | Limited | Good | Good | Pre-made by the designer |
| Best for | Rich experiences and scroll storytelling | Simple effects | React interfaces | Lightweight animation | Animated illustrations |

- **GSAP vs CSS animations**: for a hover effect or a simple entrance, CSS is enough and adds no weight. GSAP is needed when there are many animations, coordinated with each other or tied to scrolling.
- **GSAP vs Motion**: Motion is very convenient for animating interfaces built in React (elements appearing, transitions between states). GSAP is more powerful for narrative experiences and works with any technology.
- **GSAP vs Lottie**: Lottie plays animations a designer created in After Effects, ideal for icons and illustrations. GSAP animates the page's real elements. They're often used together.

### When to choose it (and when not)

**Yes**, when the visual experience is part of the brand's value: product launches, landing pages, design, fashion and luxury sites, stories that unfold as you scroll.

**No**, if you only need a few simple effects (CSS animations are enough, with no extra weight), or if the site must be essentially functional and quick to use, like a B2B catalogue or a customer area. There, animation should be kept to a minimum.
